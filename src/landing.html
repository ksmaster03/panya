ใหม่โฮสต์เอง ข้อมูลอยู่บนเซิร์ฟเวอร์ของเรา

สมองที่สองของทีม จำทุกอย่างตามจริง ตอบเมื่อรู้ บอกเมื่อไม่รู้

panya เก็บความจำของทีมแบบคำต่อคำ ค้นได้ทั้งภาษาไทยและอังกฤษ และไม่เดาคำตอบเอง ถ้าไม่มีข้อมูลจริงก็จะบอกตรง ๆ ว่าไม่รู้

เข้าสู่ระบบ ดูวิธีใช้ API
  • ไม่ใช้ AI แต่งข้อความ
  • REST API ใช้ได้ทุกภาษา
  • ไม่รับเก็บความลับ

ความสามารถ

ความจำที่ทีมเชื่อได้ เพราะไม่มีการแต่งเติม

ออกแบบมาให้ทั้งคนและ AI agent ใช้ร่วมกัน ข้อมูลที่เก็บคือข้อมูลที่ได้กลับ ไม่มีอะไรถูกเขียนใหม่ระหว่างทาง

เก็บตามจริง ไม่แต่งเติม

ข้อความถูกเก็บแบบคำต่อคำ ไม่มี LLM มาสรุปหรือเขียนใหม่ ค้นเจอเมื่อไรก็ได้ข้อความเดิมทุกตัวอักษร

ไม่รู้ก็บอกว่าไม่รู้

ถ้าไม่มีความจำไหนตรงกับคำถามพอ panya จะตอบว่า abstained: true แทนการยัดผลลัพธ์ที่ไม่เกี่ยวมาให้

ค่าใหม่แทนค่าเก่าอัตโนมัติ

ระบุ subject กับ attribute แล้วเมื่อข้อมูลเรื่องเดียวกันเปลี่ยน ค่าล่าสุดจะแทนที่ค่าเก่าให้เอง ไม่ต้องตามลบ

ค้นได้ทั้งไทยและอังกฤษ

ค้นแบบผสมทั้งความหมาย (embedding) และคำตรงตัว ตัดคำไทยได้ถูก ถามเป็นไทยก็เจอข้อความภาษาอังกฤษได้

สมองของแต่ละคน แชร์ให้อ่านได้

ทุกคนมีสมองของตัวเอง เจ้าของเลือกได้ว่าจะแชร์ให้ใครอ่าน คนที่ได้รับแชร์อ่านได้อย่างเดียว แก้ไม่ได้

ภาพสามมิติ: แดชบอร์ด สมอง คลังสินค้า

ดูความจำเป็นภาพสามมิติได้สามมุม ทั้งแดชบอร์ดภาพรวม แผนที่สมอง และคลังสินค้าที่จัดความจำเป็นชั้นวาง

ทำงานอย่างไร

สามขั้นตอน ตั้งแต่ส่งความจำจนถึงได้คำตอบ

  1. 1

    ส่งความจำผ่าน API หรือหน้าเว็บ

    ส่งทีละรายการหรือครั้งละหลายรายการ จากสคริปต์ AI agent หรือพิมพ์เองในหน้าเว็บก็ได้

  2. 2

    panya ตรวจ ตัดซ้ำ แล้วจัดเก็บ

    ตรวจว่ามีรหัสผ่านหรือ key ปนมาไหม รวมข้อความที่ซ้ำกัน แล้วเก็บพร้อม embedding สำหรับค้นตามความหมาย

  3. 3

    ค้นแล้วได้ข้อความเดิม หรือคำตอบว่าไม่รู้

    ผลลัพธ์คือข้อความต้นฉบับพร้อมคะแนน ถ้าไม่มีอะไรตรงพอก็ได้ abstained แทนการเดา

ใช้ผ่าน API

เริ่มใช้งาน API ได้ในไม่กี่นาที

REST API ธรรมดา ส่งและรับเป็น JSON เรียกได้จากทุกภาษา ทุกคำขอแนบ API key ไว้ในส่วนหัว

  1. 1

    เข้าสู่ระบบแล้วสร้าง API key

    ไปที่หน้า บัญชีและ API แล้วกดสร้าง key ใหม่ key จะขึ้นต้นด้วย pnu_ และแสดงให้เห็นแค่ครั้งเดียว เก็บไว้ให้ดี

  2. 2

    สร้างสมองสำหรับเก็บความจำ

    ที่หน้า สมองของฉัน ตั้งชื่อสมอง เช่น my-notes ชื่อนี้คือค่า brain ที่ส่งในทุกคำขอ

  3. 3

    บันทึกและค้นหา

    ลองตัวอย่างทางขวา เลือกภาษาที่ถนัดแล้วกดคัดลอกไปใช้ได้เลย แค่เปลี่ยน pnu_xxx เป็น key ของคุณ

POST/v1/memories
201ตัวอย่างผลลัพธ์ (ย่อ)

ทุกคำขอต้องมีส่วนหัว Authorization: Bearer pnu_xxx

รายการ endpoint หลัก

เมธอดเส้นทางใช้ทำอะไร
POST/v1/memoriesบันทึกความจำหนึ่งรายการ
POST/v1/memories/batchบันทึกหลายรายการ สูงสุด 200 รายการต่อคำขอ
POST/v1/searchค้นหา ได้ข้อความเดิมพร้อมคะแนน หรือ abstained เมื่อไม่รู้
GET/v1/brainsดูรายชื่อสมองที่คุณเป็นเจ้าของหรือได้รับแชร์
GET/v1/export?brain=…ส่งออกความจำทั้งหมดของสมอง
DELETE/v1/memories/:id?brain=…ลบความจำหนึ่งรายการ

ข้อความแต่ละรายการยาวได้ไม่เกิน 2,000 ตัวอักษร

ความปลอดภัย

ปลอดภัยตั้งแต่การออกแบบ

กติกาเหล่านี้บังคับใช้ที่เซิร์ฟเวอร์ ไม่ได้ขึ้นกับว่าผู้ใช้จะระวังแค่ไหน

  • ห้ามเก็บรหัสผ่าน key หรือ token

    panya ปฏิเสธให้อัตโนมัติ ตอบกลับเป็น 400 refused: looks like a password, key or token

  • เขียนได้เฉพาะสมองของตัวเอง

    สมองของคนอื่นอ่านได้เมื่อเจ้าของแชร์ให้เท่านั้น และอ่านได้อย่างเดียว

  • ยกเลิก key ได้ทุกเมื่อ

    key เก็บเป็นค่า hash เท่านั้น แม้ฐานข้อมูลรั่วก็เอาไปใช้ต่อไม่ได้

  • รหัสผ่านเข้ารหัสด้วย argon2id

    อัลกอริทึมที่แนะนำในปัจจุบัน ทนต่อการเดารหัสด้วย GPU

  • ล็อกอินผิด 5 ครั้ง พัก 15 นาที

    กันการสุ่มรหัสผ่านซ้ำ ๆ จากภายนอก

  • ข้อมูลอยู่บนเซิร์ฟเวอร์ของเราเอง

    ติดตั้งบน AWS ภูมิภาคกรุงเทพ ไม่ส่งข้อมูลไปให้บริการ AI ภายนอก

พร้อมให้ทีมมีความจำที่เชื่อถือได้แล้วหรือยัง

เข้าสู่ระบบ สร้าง key แล้วส่งความจำแรกได้ภายในไม่กี่นาที
